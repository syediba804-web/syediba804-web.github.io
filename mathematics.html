Fractions, decimals, percentages

a/b + c/d = (ad + bc)/(bd) · a/b × c/d = ac/bd · a/b ÷ c/d = a/b × d/c
  • 3/4 = 0.75 = 75%
  • Percentage of a number: 15% of 80 = 0.15 × 80 = 12
  • Percentage change = (new − old) ÷ old × 100

Divisibility, primes, factors

  • Divisible by 2: last digit even. By 3: digit sum divisible by 3. By 5: ends in 0 or 5. By 9: digit sum divisible by 9.
  • Prime: exactly two factors (2, 3, 5, 7, 11, 13, ...).
  • GCD (greatest common divisor) and LCM (least common multiple): gcd(12, 18) = 6, lcm(12, 18) = 36, and gcd × lcm = product.

2. Algebra basics Beginner

A variable stands for an unknown number. To solve an equation, do the same thing to both sides until the variable is alone.

3x − 7 = 11 → 3x = 18 → x = 6

Expanding and factorising

(a + b)² = a² + 2ab + b² · (a − b)² = a² − 2ab + b² · (a + b)(a − b) = a² − b²
x² + 5x + 6 = (x + 2)(x + 3)

Inequalities

Solve like equations, but flip the sign when multiplying or dividing by a negative: −2x < 6 → x > −3.

Simultaneous equations

x + y = 10 and x − y = 4 → add them: 2x = 14, x = 7, y = 3

Lines

y = mx + c (m = slope, c = y-intercept) · slope = (y₂ − y₁)/(x₂ − x₁)

3. Quadratics Intermediate

ax² + bx + c = 0 → x = (−b ± √(b² − 4ac)) / 2a

The discriminant D = b² − 4ac tells you the number of real roots: D > 0 two roots, D = 0 one root, D < 0 none.

x² − 4x − 5 = 0 → D = 16 + 20 = 36 → x = (4 ± 6)/2 → x = 5 or −1

The graph is a parabola with vertex at x = −b/2a. It opens upward if a > 0 and downward if a < 0.

Completing the square

x² + 6x + 1 = (x + 3)² − 8

4. Functions, exponentials and logarithms Intermediate

A function f assigns each input exactly one output: f(x) = 2x + 1 gives f(3) = 7. The domain is the allowed inputs; the range is the outputs.

Composition: (f ∘ g)(x) = f(g(x)) · Inverse: f⁻¹(f(x)) = x

Logarithms (the inverse of exponentials)

log_b(x) = y ⇔ bʸ = x · log₂(8) = 3 · log₁₀(1000) = 3
log(xy) = log x + log y · log(x/y) = log x − log y · log(xⁿ) = n·log x
Why CS caresBinary search takes about log₂(n) steps, and a number n needs about log₂(n) bits to store.

Binary and hexadecimal

  • Binary: 1101₂ = 8 + 4 + 0 + 1 = 13
  • Decimal to binary: divide by 2 repeatedly and read the remainders backwards (13 → 1101).
  • Hex digits: 0-9, A-F where A = 10 ... F = 15. 0xFF = 255.

De Morgan: ¬(P ∧ Q) = ¬P ∨ ¬Q · ¬(P ∨ Q) = ¬P ∧ ¬Q

Sets

A = {1, 2, 3}, B = {3, 4} → A ∪ B = {1, 2, 3, 4} · A ∩ B = {3} · A − B = {1, 2}

The size of a set is |A|. Inclusion-exclusion: |A ∪ B| = |A| + |B| − |A ∩ B|. A set with n elements has 2ⁿ subsets.

Proof ideas

  • Direct proof: start from the assumptions and reach the conclusion.
  • Contradiction: assume the opposite and show it is impossible.
  • Induction: prove the first case, then show "if true for k, then true for k+1".
Induction example: 1 + 2 + ... + n = n(n + 1)/2

6. Modular arithmetic Intermediate

a mod n is the remainder when a is divided by n. It behaves like a clock: after 12 comes 1.

25 mod 7 = 4 · (−1) mod 5 = 4 · a ≡ b (mod n) means n divides a − b
(a + b) mod n = ((a mod n) + (b mod n)) mod n · same for ×

Uses: hash tables (hash(key) % size), checking even/odd, cyclic buffers, calendars, and cryptography.

Euclid's algorithm for GCD

gcd(48, 18) → gcd(18, 12) → gcd(12, 6) → gcd(6, 0) = 6

7. Counting: permutations and combinations Intermediate

  • Multiplication rule: independent choices multiply (3 shirts × 4 pants = 12 outfits).
  • Factorial: n! = n × (n−1) × ... × 1, and 0! = 1.
Permutations (order matters): P(n, r) = n! / (n − r)!
Combinations (order doesn't): C(n, r) = n! / (r!(n − r)!)
Choose 3 from 5 as a team: C(5, 3) = 5!/(3!·2!) = 10
Pick president, VP, treasurer from 5: P(5, 3) = 5 × 4 × 3 = 60

Passwords: 8 characters from 62 letters/digits gives 62⁸ ≈ 2.2 × 10¹⁴ possibilities.

Pigeonhole principleIf you put n+1 items into n boxes, some box has at least two items.

8. Probability Beginner Intermediate

P(event) = favourable outcomes / total outcomes (equally likely) · 0 ≤ P ≤ 1
  • Complement: P(not A) = 1 − P(A)
  • Independent events: P(A and B) = P(A) × P(B)
  • Either event: P(A or B) = P(A) + P(B) − P(A and B)
  • Conditional: P(A | B) = P(A and B) / P(B)
Two coins both heads: 1/2 × 1/2 = 1/4
At least one 6 in two rolls: 1 − (5/6)² = 11/36

Expected value

E = Σ (value × probability). A fair die: (1+2+3+4+5+6)/6 = 3.5

Bayes' theorem

P(A | B) = P(B | A) · P(A) / P(B)

Normal distribution

The "bell curve". About 68% of values lie within 1 standard deviation of the mean, 95% within 2 and 99.7% within 3.

Correlation

Correlation measures how two variables move together (from −1 to +1). Correlation does not mean causation.

data = [2, 4, 4, 6, 9]
print(st.mean(data), st.median(data), st.mode(data), st.pstdev(data))

12. Vectors and matrices Intermediate

A vector is an ordered list of numbers (a point or a direction). A matrix is a grid of numbers.

a = (1, 2), b = (3, 4) → a + b = (4, 6) · 3a = (3, 6)
Dot product: a · b = 1×3 + 2×4 = 11 · |a| = √(1² + 2²) = √5

Matrix multiplication

Row × column. A (2×3) times a (3×2) gives a (2×2). Order matters: AB ≠ BA in general.

[1 2; 3 4] · [5 6; 7 8] = [1·5+2·7, 1·6+2·8; 3·5+4·7, 3·6+4·8] = [19 22; 43 50]
Determinant of [a b; c d] = ad − bc · Identity matrix I: AI = A
import numpy as np
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
print(A @ B)              # matrix product
print(np.linalg.det(A))   # -2.0
