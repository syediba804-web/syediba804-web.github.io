1. Getting started Beginner

Python is a readable, general-purpose language used for web development, data science, automation, AI and more. Python code is executed line by line by the interpreter.

Your first program

print("Hello, world!")
print("My name is Ibraheem")
Hello, world! My name is Ibraheem

Comments

# This is a comment: Python ignores it
print("Comments explain your code")  # inline comment
TipInstall Python from python.org, check it with python --version, and run a file with python myfile.py.

2. Variables and data types Beginner

A variable is a name that points to a value. You don't declare a type; Python works it out.

name = "Ibraheem"     # str
age = 20              # int
height = 5.9          # float
is_student = True     # bool

print(type(name), type(age), type(height), type(is_student))
TypeExampleUse

Naming rules

  • Start with a letter or underscore, never a digit.
  • Use letters, digits and underscores only.
  • Names are case-sensitive: age and Age differ.
  • Style: snake_case for variables and functions.

Type conversion

x = int("42")        # 42
y = float("3.5")     # 3.5
z = str(100)         # "100"
print(int(7.9))      # 7 (cuts the decimal part)

4. Conditions: if, elif, else Beginner

Python uses indentation (4 spaces) to mark blocks. It is part of the syntax.

marks = 78
if marks >= 90:
    grade = "A"
elif marks >= 75:
    grade = "B"
elif marks >= 60:
    grade = "C"
else:
    grade = "Needs work"
print(grade)
B

Truthy and falsy

Falsy values: 0, 0.0, "", [], {}, set(), None, False. Everything else is truthy.

items = []
if not items:
    print("The list is empty")

One-line conditional

status = "adult" if age >= 18 else "minor"

count = 3

break, continue, else

for n in range(1, 10):
    if n % 2 == 0:
        continue        # skip even numbers
    if n > 7:
        break           # stop the loop completely
    print(n)
Tiprange(start, stop, step) stops before stop. range(10, 0, -2) counts down: 10, 8, 6, 4, 2.

7. Lists, tuples, sets and dictionaries Beginner

List: ordered and changeable

nums = [5, 3, 8]
nums.append(1)         # [5, 3, 8, 1]
nums.insert(0, 10)     # [10, 5, 3, 8, 1]
nums.remove(3)         # remove first 3
last = nums.pop()      # removes and returns 1
nums.sort()            # sort in place
print(nums, len(nums), sum(nums), max(nums))

Tuple: ordered, NOT changeable

point = (3, 4)
x, y = point           # unpacking

Set: unique items, no order

a = {1, 2, 3}
b = {3, 4}
print(a | b)   # union        {1, 2, 3, 4}
print(a & b)   # intersection {3}
print(a - b)   # difference   {1, 2}

Dictionary: key to value

student = {"name": "Sara", "age": 19}
student["city"] = "Karachi"
print(student.get("grade", "N/A"))

for key, value in student.items():
    print(key, "->", value)

Slicing and comprehensions

squares = [n * n for n in range(1, 6)]            # [1, 4, 9, 16, 25]
evens   = [n for n in range(10) if n % 2 == 0]    # [0, 2, 4, 6, 8]
lengths = {w: len(w) for w in ["hi", "python"]}   # {'hi': 2, 'python': 6}

8. Functions Beginner Intermediate

def greet(name, greeting="Hello"):
    """Return a greeting message."""
    return f"{greeting}, {name}!"

print(greet("Ali"))
print(greet("Sara", greeting="Salam"))

*args and **kwargs

def total(*numbers):
    return sum(numbers)

def show(**info):
    for k, v in info.items():
        print(k, v)

print(total(1, 2, 3, 4))     # 10
show(name="Ali", age=20)

Scope

Variables created inside a function are local. Prefer passing values in and returning results out instead of using global.

Lambda, map, filter

double = lambda x: x * 2
print(list(map(double, [1, 2, 3])))              # [2, 4, 6]
print(list(filter(lambda x: x > 1, [1, 2, 3])))  # [2, 3]
people = [("Ali", 20), ("Sara", 18)]
people.sort(key=lambda p: p[1])                  # sort by age
Classic bugNever use a mutable default like def f(x=[]). It is shared between calls. Use x=None and create the list inside.

9. Error handling Intermediate

try:
    n = int(input("Number: "))
    print(10 / n)
except ValueError:
    print("That was not a number")
except ZeroDivisionError:
    print("Cannot divide by zero")
else:
    print("No errors!")
finally:
    print("Done.")

Raising your own error

def set_age(age):

11. Classes and objects Intermediate

class Student:
    school = "KU"                      # class attribute

    def __init__(self, name, marks):
        self.name = name               # instance attributes
        self.marks = marks

    def average(self):
        return sum(self.marks) / len(self.marks)

    def __str__(self):
        return f"{self.name} ({self.average():.1f})"

s = Student("Sara", [90, 80, 85])
print(s)
Sara (85.0)

Inheritance

class Animal:
    def speak(self):
        return "..."

class Dog(Animal):
    def speak(self):
        return "Woof!"

print(Dog().speak())
  • Encapsulation: keep data and behaviour together.
  • Inheritance: reuse a parent class.
  • Polymorphism: same method name, different behaviour.

12. Handy intermediate tools Intermediate

# Generators produce values one at a time
def countdown(n):
    while n > 0:
        yield n
        n -= 1
print(list(countdown(3)))      # [3, 2, 1]

# Counting with collections
from collections import Counter
print(Counter("banana"))       # Counter({'a': 3, 'n': 2, 'b': 1})
