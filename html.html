HTML: Beginner to Intermediate

Build the structure of web pages: text, links, images, lists, tables, forms and semantic layout, plus accessibility and best practices.

1. What is HTML? Beginner

HTML (HyperText Markup Language) describes the structure and meaning of a web page. CSS styles it and JavaScript makes it interactive.

Anatomy of an element

<p class="intro">Hello, world!</p>
 ^tag  ^attribute     ^content   ^closing tag

Your first page

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello!</h1>
  <p>This is my first web page.</p>
</body>
</html>
  • <head> holds information about the page (title, meta, CSS links); it isn't shown.
  • <body> holds everything visible.
  • Save as index.html and open it in a browser.

2. Headings, paragraphs and text Beginner

<h1>Main title</h1>
<h2>Section</h2>
<p>A paragraph with <strong>bold</strong>, <em>italic</em> and <mark>highlight</mark>.</p>
<p>Line one<br>Line two</p>
<hr>
<blockquote>A quoted passage.</blockquote>
<code>print("inline code")</code>
<pre>Preformatted
   text keeps spaces</pre>
TagMeaning
<strong>important text (bold)
<em>emphasis (italic)
<small>, <sub>, <sup>small, subscript, superscript (H2O, x2)
<span>generic inline wrapper
<div>generic block wrapper
SEO and accessibilityUse only one <h1> per page and don't skip heading levels (h1, then h2, then h3).

Special characters: &lt; shows <, &amp; shows &, &copy; shows ©.

3. Links Beginner

<a href="https://github.com">GitHub</a>                       <!-- external -->
<a href="about.html">About page</a>                          <!-- same folder -->
<a href="notes/python.html">Python notes</a>                  <!-- subfolder -->
<a href="#contact">Jump to contact section</a>                <!-- same page -->
<a href="mailto:me@example.com">Email me</a>
<a href="https://example.com" target="_blank" rel="noopener">New tab</a>
Paths../ means "go up one folder". From notes/python.html, the portfolio is ../index.html.
SecurityAlways add rel="noopener" when using target="_blank".

4. Images and media Beginner

<img src="photo.jpg" alt="Ibraheem at his desk" width="400" loading="lazy">

<figure>
  <img src="chart.png" alt="Bar chart of scores">
  <figcaption>Figure 1: Test scores</figcaption>
</figure>

<video src="intro.mp4" controls width="400"></video>
<audio src="song.mp3" controls></audio>
  • Always write meaningful alt text; use alt="" for purely decorative images.
  • Prefer modern formats like WebP or AVIF and resize big photos before uploading.
  • Responsive images: <img srcset="small.jpg 480w, large.jpg 1200w" sizes="100vw" ...>

5. Lists Beginner

<ul>                       <!-- bullets -->
  <li>HTML</li>
  <li>CSS</li>
</ul>

<ol start="1">                <!-- numbers -->
  <li>Plan</li>
  <li>Build</li>
</ol>

<dl>                        <!-- description list -->
  <dt>HTML</dt><dd>Structure of a page</dd>
  <dt>CSS</dt><dd>Style of a page</dd>
</dl>

Lists can be nested: put a new <ul> inside an <li>. Menus are normally built as lists of links.

6. Tables Beginner

<table>
  <caption>Exam results</caption>
  <thead>
    <tr><th>Name</th><th>Maths</th><th>CS</th></tr>
  </thead>
  <tbody>
    <tr><td>Ali</td><td>90</td><td>85</td></tr>
    <tr><td>Sara</td><td>95</td><td>92</td></tr>
  </tbody>
  <tfoot>
    <tr><td colspan="3">Updated Oct 2026</td></tr>
  </tfoot>

colspan merges columns and rowspan merges rows. Use tables for data, never for page layout.

7. Forms Beginner Intermediate

<form action="/submit" method="post">
  <label for="name">Name</label>
  <input type="text" id="name" name="name" required placeholder="Your name">

  <label for="email">Email</label>
  <input type="email" id="email" name="email" required>

  <label for="age">Age</label>
  <input type="number" id="age" name="age" min="5" max="100">

  <label for="pw">Password</label>
  <input type="password" id="pw" name="pw" minlength="8">

  <fieldset>
    <legend>Level</legend>
    <label><input type="radio" name="level" value="beg"> Beginner</label>
    <label><input type="radio" name="level" value="int"> Intermediate</label>
  </fieldset>

  <label><input type="checkbox" name="news"> Send me updates</label>

  <label for="city">City</label>
  <select id="city" name="city">
    <option value="khi">Karachi</option>
    <option value="lhe">Lahore</option>
  </select>

  <label for="msg">Message</label>
  <textarea id="msg" name="msg" rows="4"></textarea>

  <button type="submit">Send</button>
</form>

Useful input types

text, email, password, number, date, time, color, range, file, url, tel, search, checkbox, radio, hidden.

Built-in validation

required, minlength, maxlength, min, max, pattern="[A-Za-z]+". The browser blocks submission and shows a message.

AccessibilityEvery input needs a <label> whose for matches the input's id. Clicking the label then focuses the field.
Try it: a live form (nothing is sent).

8. Semantic layout Intermediate

Semantic tags tell browsers, search engines and screen readers what each part means, which is better than a pile of <div>s.

<body>
  <header>
    <h1>My Portfolio</h1>
    <nav>
      <a href="#about">About</a>
      <a href="#projects">Projects</a>
    </nav>
  </header>

  <main>
    <section id="about">
      <h2>About</h2>
      <p>...</p>
    </section>

    <article>
      <h2>Blog post</h2>
      <p>...</p>
    </article>

    <aside>Related links</aside>
  </main>

  <footer>&copy; 2026 Ibraheem</footer>
</body>
TagUse
<header>intro or top of page/section
<nav>main navigation
<main>the page's main content (once per page)
<section>a themed group, usually with a heading
<article>self-contained piece (post, card)
<aside>side content
<footer>bottom of page/section

9. Attributes, id and class Beginner Intermediate

  • id: a unique name for one element (used for CSS, links and JS).
  • class: a reusable label; many elements can share it, and one element can have several.
  • style: inline CSS (avoid; prefer a stylesheet).
  • data-*: your own data, e.g. data-level="beginner".
  • title: tooltip text; hidden: hides an element.
<div id="hero" class="card featured" data-level="beginner">...</div>

Connecting CSS and JavaScript

<head>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  ...
  <script src="app.js" defer></script>
</body>

10. Accessibility and SEO basics Intermediate

  • Write meaningful alt text and link text ("Read the Python notes", not "click here").
  • Use semantic tags and a logical heading order.
  • Make sure everything works with the keyboard (Tab, Enter, Space).
  • Keep good colour contrast.
  • Set <html lang="en">, a unique <title> and a <meta name="description">.
  • ARIA is a last resort: aria-label="Close menu" on an icon-only button, for example.
<button aria-label="Close menu">✕</button>
<a href="#main" class="skip">Skip to content</a>
