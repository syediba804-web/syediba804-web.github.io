Data Structures: Beginner to Intermediate

How to organise data so programs stay fast and clean: arrays, linked lists, stacks, queues, hash tables, trees, heaps and graphs, all in Python.

1. Why data structures matter Beginner

A data structure is a way of storing data so certain operations are fast. Choosing the right one often matters more than clever code.

2. Arrays and lists Beginner

An array stores items next to each other in memory, so jumping to index i is instant. Python's list is a dynamic array that grows automatically.

a = [10, 20, 30, 40]
print(a[2])          # 30, O(1)
a.append(50)         # O(1) on average
a.insert(0, 5)       # O(n): everything shifts right
a.pop()              # O(1) from the end
a.pop(0)             # O(n) from the front

2D arrays (grids)

grid = [[0] * 3 for _ in range(3)]    # correct: 3 independent rows
grid[1][2] = 7
# Warning: [[0] * 3] * 3 makes 3 references to the SAME row!

Two pointers and sliding window

# Maximum sum of any 3 consecutive numbers
def max_window(nums, k):
    window = sum(nums[:k])
    best = window
    for i in range(k, len(nums)):
        window += nums[i] - nums[i - k]
        best = max(best, window)
    return best

print(max_window([2, 1, 5, 1, 3, 2], 3))   # 9

3. Linked lists Beginner Intermediate

Each node holds a value and a pointer to the next node. No shifting is needed to insert, but reaching item i means walking from the head.

class Node:
    def __init__(self, value):
        self.value = value
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None

    def add_first(self, value):          # O(1)
        node = Node(value)
        node.next = self.head
        self.head = node

    def add_last(self, value):           # O(n)
        node = Node(value)
        if not self.head:
            self.head = node
            return
        cur = self.head
        while cur.next:
            cur = cur.next
        cur.next = node

    def to_list(self):
        out, cur = [], self.head
        while cur:
            out.append(cur.value)
            cur = cur.next
        return out

ll = LinkedList()
ll.add_last(2); ll.add_last(3); ll.add_first(1)
print(ll.to_list())     # [1, 2, 3]

Reverse a linked list

def reverse(head):
    prev = None
    while head:
        head.next, prev, head = prev, head, head.next
    return prev
VariantsDoubly linked lists keep a prev pointer too. Circular lists link the tail back to the head.

4. Stacks (LIFO) Beginner

Last in, first out. Think of a pile of plates. Operations: push, pop, peek.

stack = []
stack.append("a")      # push
stack.append("b")
print(stack[-1])       # peek: b
print(stack.pop())     # pop: b

Classic use: balanced brackets

def balanced(text):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in text:
        if ch in "([{":
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
    return not stack

print(balanced("{[()]}"), balanced("(]"))   # True False

Other uses: undo/redo, browser back button, function call stack, evaluating expressions.

5. Queues (FIFO) Beginner

First in, first out. Use collections.deque, because list.pop(0) is slow.

from collections import deque
q = deque()
q.append("Ali")        # enqueue
q.append("Sara")
print(q.popleft())     # dequeue: Ali
print(q)               # deque(['Sara'])

Priority queue

import heapq
tasks = []
heapq.heappush(tasks, (2, "write report"))
heapq.heappush(tasks, (1, "fix bug"))
print(heapq.heappop(tasks))    # (1, 'fix bug'): lowest number first

6. Hash tables: dict and set Beginner Intermediate

A hash function turns a key into a number that picks a storage slot, so lookups are about O(1). When two keys land in the same slot it is a collision, handled by chaining or probing.

ages = {"Ali": 20, "Sara": 19}
print("Ali" in ages)            # True, fast
ages["Zain"] = 21

# Frequency counting
text = "mississippi"
freq = {}
for ch in text:
    freq[ch] = freq.get(ch, 0) + 1
print(freq)    # {'m': 1, 'i': 4, 's': 4, 'p': 2}
RuleDictionary keys must be hashable (immutable): strings, numbers, tuples are OK; lists are not.

Anagram check

def is_anagram(a, b):
    return sorted(a) == sorted(b)

7. Trees and binary search trees Intermediate

A tree is a hierarchy of nodes. In a binary search tree (BST): left subtree < node < right subtree.

class TreeNode:
    def __init__(self, key):
        self.key = key
        self.left = None
        self.right = None

def insert(root, key):
    if root is None:
        return TreeNode(key)
    if key < root.key:
        root.left = insert(root.left, key)
    else:
        root.right = insert(root.right, key)
    return root

def search(root, key):
    if root is None or root.key == key:
        return root
    return search(root.left if key < root.key else root.right, key)

def inorder(root):                 # gives sorted order
    if root:
        yield from inorder(root.left)
        yield root.key
        yield from inorder(root.right)

root = None
for k in [8, 3, 10, 1, 6, 14]:
    root = insert(root, k)
print(list(inorder(root)))     # [1, 3, 6, 8, 10, 14]

Traversals

  • In-order: left, node, right (sorted for a BST)
  • Pre-order: node, left, right (copying a tree)
  • Post-order: left, right, node (deleting a tree)
  • Level-order: row by row, using a queue
def height(node):
    return 0 if node is None else 1 + max(height(node.left), height(node.right))
BalanceA BST built from sorted input becomes a long chain (O(n)). Balanced trees such as AVL and Red-Black keep O(log n).

8. Heaps Intermediate

A heap is a complete binary tree where each parent is smaller (min-heap) or larger (max-heap) than its children. The minimum is always at the top, and push/pop cost O(log n).

import heapq
nums = [7, 2, 9, 4, 1]
heapq.heapify(nums)               # O(n)
print(heapq.heappop(nums))        # 1
print(heapq.nsmallest(2, nums))   # [2, 4]

# Max-heap trick: store negatives
mx = []
for n in [3, 8, 5]:
    heapq.heappush(mx, -n)
print(-heapq.heappop(mx))         # 8

Uses: priority queues, scheduling, finding the k largest items, Dijkstra's algorithm.

9. Graphs Intermediate

A graph is nodes (vertices) joined by edges. Edges can be directed or undirected, weighted or not. The most common representation is an adjacency list.

graph = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["B", "C"],
}

Breadth-first search (shortest path by number of edges)

from collections import deque

def bfs(graph, start):
    seen = {start}
    q = deque([start])
    order = []
    while q:
        node = q.popleft()
        order.append(node)
        for nxt in graph[node]:
            if nxt not in seen:
                seen.add(nxt)
                q.append(nxt)
    return order

print(bfs(graph, "A"))    # ['A', 'B', 'C', 'D']

Depth-first search

def dfs(graph, node, seen=None):
    seen = seen if seen is not None else set()
    seen.add(node)
    for nxt in graph[node]:
        if nxt not in seen:
            dfs(graph, nxt, seen)
    return seen
RememberBFS uses a queue and explores level by level. DFS uses a stack (or recursion) and goes deep first.
