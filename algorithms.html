Algorithms: Beginner to Intermediate

Learn to think in steps: measure efficiency, search, sort, use recursion, and meet greedy and dynamic programming. Examples are in Python.

9 topics10-question quiz7 assignments

1. What is an algorithm? Beginner

An algorithm is a clear, finite list of steps that turns input into output. A good algorithm is correct, efficient and easy to understand.

Example: find the largest number

def largest(nums):
    best = nums[0]
    for n in nums[1:]:
        if n > best:
            best = n
    return best

print(largest([4, 9, 2, 7]))
9

Problem-solving recipe

  1. Understand the problem: inputs, outputs, examples.
  2. Work a small example by hand.
  3. Write the steps in plain words (pseudocode).
  4. Code it, then test with normal and edge cases (empty list, one item, duplicates).
  5. Ask: can it be faster?

2. Measuring efficiency: Big-O Beginner

Big-O describes how the number of steps grows as the input size n grows. We ignore constants and small terms.

def has_duplicate(items):        # O(n²): nested loops
    for i in range(len(items)):
        for j in range(i + 1, len(items)):
            if items[i] == items[j]:
                return True
    return False

def has_duplicate_fast(items):   # O(n): a set remembers what we saw
    seen = set()
    for x in items:
        if x in seen:
            return True
        seen.add(x)
    return False
Rule of thumbOne loop over n items is O(n). A loop inside a loop is O(n²). Halving the problem each step is O(log n).

Space complexity counts the extra memory an algorithm uses, measured the same way.

3. Searching Beginner

Linear search: O(n)

def linear_search(items, target):
    for i, x in enumerate(items):
        if x == target:
            return i
    return -1

Binary search: O(log n), data must be sorted

def binary_search(items, target):
    low, high = 0, len(items) - 1
    while low <= high:
        mid = (low + high) // 2
        if items[mid] == target:
            return mid
        elif items[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

print(binary_search([1, 3, 5, 7, 9, 11], 7))   # 3
Trace itSearching 7 in [1,3,5,7,9,11]: mid=5 (index 2) < 7, go right; mid=9 (index 4) > 7, go left; mid=7 (index 3), found.

4. Simple sorting Beginner

Bubble sort: O(n²)

Repeatedly swap neighbours that are in the wrong order. Large values "bubble" to the end.

def bubble_sort(a):
    n = len(a)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True
        if not swapped:      # already sorted, stop early
            break
    return a

Selection sort: O(n²)

def selection_sort(a):
    for i in range(len(a)):
        m = min(range(i, len(a)), key=lambda k: a[k])
        a[i], a[m] = a[m], a[i]
    return a

Insertion sort: O(n²), fast on nearly sorted data

def insertion_sort(a):
    for i in range(1, len(a)):
        key = a[i]
        j = i - 1
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
    return a
In real projectsJust use sorted(list) or list.sort(). It is O(n log n) and very well optimised.

5. Recursion Beginner Intermediate

A function that calls itself on a smaller problem. It needs a base case (stop) and a recursive case.

def factorial(n):
    if n <= 1:            # base case
        return 1
    return n * factorial(n - 1)

print(factorial(5))     # 120

Call stack for factorial(3): 3 × factorial(2) → 2 × factorial(1) → returns 1, then 2, then 6.

def power(base, exp):
    if exp == 0:
        return 1
    half = power(base, exp // 2)
    return half * half if exp % 2 == 0 else half * half * base

def sum_digits(n):
    return n if n < 10 else n % 10 + sum_digits(n // 10)
DangerMissing base case means infinite recursion and a RecursionError. Python's default limit is about 1000 calls.

6. Divide and conquer: merge sort and quick sort Intermediate

Split the problem, solve the parts, combine the answers.

Merge sort: O(n log n)

def merge_sort(a):
    if len(a) <= 1:
        return a
    mid = len(a) // 2
    left = merge_sort(a[:mid])
    right = merge_sort(a[mid:])
    return merge(left, right)

def merge(left, right):
    out, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            out.append(left[i]); i += 1
        else:
            out.append(right[j]); j += 1
    return out + left[i:] + right[j:]

Quick sort: O(n log n) average, O(n²) worst

def quick_sort(a):
    if len(a) <= 1:
        return a
    pivot = a[len(a) // 2]
    less    = [x for x in a if x < pivot]
    equal   = [x for x in a if x == pivot]
    greater = [x for x in a if x > pivot]
    return quick_sort(less) + equal + quick_sort(greater)

7. Greedy algorithms Intermediate

At every step take the choice that looks best right now. It works when local choices lead to a global best.

Coin change (works for standard coin sets)

def make_change(amount, coins=(25, 10, 5, 1)):
    result = []
    for c in coins:                # coins in descending order
        while amount >= c:
            amount -= c
            result.append(c)
    return result

print(make_change(68))   # [25, 25, 10, 5, 1, 1, 1]

Activity selection

To fit the most non-overlapping meetings, sort by end time and always pick the next meeting that starts after the last one ended.

Not always correctWith coins {1, 3, 4} and amount 6, greedy gives 4+1+1 (3 coins) but the best is 3+3 (2 coins). That is where dynamic programming steps in.

8. Dynamic programming basics Intermediate

If a problem breaks into overlapping subproblems, solve each once and store the answer.

Fibonacci: slow vs fast

def fib_slow(n):                 # O(2ⁿ)
    return n if n < 2 else fib_slow(n - 1) + fib_slow(n - 2)

from functools import lru_cache
@lru_cache(maxsize=None)
def fib(n):                      # O(n) with memoization
    return n if n < 2 else fib(n - 1) + fib(n - 2)

print(fib(50))   # 12586269025

Coin change (fewest coins) with a table

def min_coins(coins, amount):
    INF = float("inf")
    dp = [0] + [INF] * amount
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a:
                dp[a] = min(dp[a], dp[a - c] + 1)
    return dp[amount] if dp[amount] != INF else -1

print(min_coins([1, 3, 4], 6))   # 2

9. Backtracking Intermediate

Try a choice, explore, and undo it if it fails. Used for permutations, mazes, Sudoku and N-Queens.

def permutations(items, current=None):
    current = current or []
    if not items:
        print(current)
        return
    for i in range(len(items)):
        permutations(items[:i] + items[i+1:], current + [items[i]])
