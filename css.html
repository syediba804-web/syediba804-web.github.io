1. What is CSS? Beginner

CSS (Cascading Style Sheets) controls how HTML looks: colors, fonts, spacing and layout.

selector {
  property: value;
  another-property: value;
}

h1 {
  color: teal;
  font-size: 2rem;
}

Three ways to add CSS

<!-- 1. External file (best) -->
<link rel="stylesheet" href="style.css">

<!-- 2. Internal -->
<style> p { color: gray; } </style>

<!-- 3. Inline (avoid) -->
<p style="color: red;">Hi</p>

2. Selectors Beginner

p::first-line, .x::beforepseudo-elements

Specificity and the cascade

When rules conflict, the more specific selector wins: inline style, then #id, then .class, then element. If equal, the later rule wins. Avoid !important.

Inheritance

Text properties like color and font-family pass down to children; box properties like margin do not.

5. The box model Beginner

Every element is a box: content → padding → border → margin (inside out).

* { box-sizing: border-box; }   /* put this at the top of every project */

.card {
  width: 300px;
  padding: 20px;               /* space inside */
  border: 2px solid #8b9cff;
  margin: 16px auto;           /* space outside; auto centers a block */
  border-radius: 12px;
}

/* Shorthand: top right bottom left (clockwise) */
margin: 10px 20px 10px 20px;
padding: 10px 20px;            /* vertical horizontal */
Margin collapseVertical margins between blocks can merge into the larger one instead of adding up.

Display

  • block: full width, starts a new line (div, p, h1)
  • inline: flows with text; width/height ignored (span, a)
  • inline-block: flows inline but accepts width/height
  • none: removed from the page

6. Position and overflow Intermediate

.box { position: static; }     /* default */
.nudge { position: relative; top: 10px; left: 20px; }
.badge { position: absolute; top: 0; right: 0; }   /* relative to nearest positioned ancestor */
.navbar { position: fixed; top: 0; width: 100%; }  /* stays on screen */
.sticky { position: sticky; top: 0; }              /* sticks when scrolling */

.layer { z-index: 10; }                  /* stacking order */
.scroll { overflow: auto; max-height: 200px; }
PatternPut position: relative on a parent and position: absolute on a child to pin the child inside the parent (badges, close buttons).

7. Flexbox Beginner Intermediate

Flexbox lays items out in a row or column and handles alignment and spacing easily.

.container {
  display: flex;
  flex-direction: row;           /* or column */
  justify-content: space-between; /* main axis: flex-start, center, flex-end, space-around */
  align-items: center;            /* cross axis: stretch, flex-start, flex-end */
  gap: 16px;
  flex-wrap: wrap;                /* allow wrapping onto new lines */
}
.item { flex: 1; }                /* share extra space equally */

8. CSS Grid Intermediate

Grid lays out in rows and columns at the same time, which is ideal for page layouts and card galleries.

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);   /* three equal columns */
  gap: 16px;
}

/* Auto-responsive cards, no media query needed */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 20px;
}

.wide { grid-column: span 2; }

9. Responsive design Intermediate

Make pages work on phones, tablets and desktops. Start with this in your HTML head:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Media queries

/* Mobile-first: base styles are for phones */
.layout { display: grid; gap: 16px; }

@media (min-width: 768px) {          /* tablets and up */
  .layout { grid-template-columns: 1fr 2fr; }
}
@media (min-width: 1100px) {         /* desktops */
  .layout { max-width: 1100px; margin: 0 auto; }
}

Flexible media

img { max-width: 100%; height: auto; }
h1 { font-size: clamp(1.8rem, 4vw, 3rem); }   /* min, ideal, max */
Test itOpen browser DevTools (F12) and click the device toolbar icon to preview different screen sizes.

11. Dark mode and best practices Intermediate

:root { --bg: #ffffff; --text: #111111; }

@media (prefers-color-scheme: dark) {
  :root { --bg: #0b0f1a; --text: #e8ecf8; }
}

body { background: var(--bg); color: var(--text); }
  • Reset: * { box-sizing: border-box; margin: 0; }
  • Name classes by what they are (.card), not how they look (.red-big).
  • Keep selectors short; avoid !important and deep nesting.
  • Use variables for colors and spacing so your design stays consistent.
  • Check contrast: text should be easy to read against its background.
